EXECUTIVE AGENT

โครงข่ายสร้างรายได้มาตรฐานสากล โปร่งใส ตรวจสอบได้ และปฏิบัติถูกต้องตามกฎหมายภาษีอากรและกฎระเบียบพาณิชย์อิเล็กทรอนิกส์ไทย

โครงสร้างคอมมิชชั่นและเงื่อนไขการรับเงิน

จ่ายผลตอบแทนจริงตามเงื่อนไขมาตรฐานสากลและประมวลรัษฎากร

ESSENTIAL AGENT

คอมมิชชั่นสูงสุด 15%
  • เหมาะสำหรับผู้เริ่มต้นบอกต่อธุรกิจ
  • รับส่วนแบ่งรายได้ต่อเนื่องเมื่อลูกค้ายืนยันชำระเงินสำเร็จ
  • ระบบคำนวณอัตโนมัติ ป้องกันความผิดพลาดทางบัญชี
ยอดนิยม

PRIME AGENT

คอมมิชชั่นสูงสุด 20%
  • เหมาะสำหรับนักการตลาดและเครือข่ายธุรกิจ
  • สิทธิ์การใช้เครื่องมือสนับสนุนการตลาดพรีเมียม
  • เบิกจ่ายรายได้รวดเร็วภายใต้กฎระเบียบสรรพากร

ENTERPRISE PARTNER

คอมมิชชั่นสูงสุด 25%
  • สำหรับองค์กรหรือเอเจนซี่มืออาชีพ
  • โครงสร้างรายได้พิเศษและโบนัสรายไตรมาส
  • ทีมบัญชีและกฎหมายดูแลซัพพอร์ตเอ็กซ์คลูซีฟ

ลงทะเบียนรับโค้ดพาร์ทเนอร์ (Agent Code)

กรอกข้อมูลเพื่อเปิดใช้งานระบบแดชบอร์ดติดตามรายได้และยอมรับข้อตกลงทางกฎหมาย

เบอร์โทรศัพท์มือถือ (สำหรับยืนยันตัวตน OTP)

ข้อตกลง เงื่อนไขการรับเงิน และกฎหมายพาร์ทเนอร์

1. สถานะทางกฎหมายของพาร์ทเนอร์: การสมัครเข้าร่วมโครงการพาร์ทเนอร์ (Agent) ไม่ถือเป็นการจ้างงาน การเป็นลูกจ้าง หรือตัวแทนจำหน่ายที่ผูกพันเป็นพนักงานของบริษัทฯ แต่มีสถานะเป็นผู้แนะนำอิสระ (Independent Affiliate/Agent) ภายใต้ขอบเขตสัญญาอิเล็กทรอนิกส์นี้

2. เงื่อนไขการจ่ายค่าคอมมิชชั่น (Strict Payout Condition): บริษัทฯ จะดำเนินการคำนวณและจ่ายค่าคอมมิชชั่นให้แก่พาร์ทเนอร์ ต่อเมื่อระบบของบริษัทฯ ได้รับเงินชำระค่าบริการเต็มจำนวนจากผู้สมัคร (End-User) ผ่าน Agent Code ของพาร์ทเนอร์รายนั้นๆ สำเร็จสมบูรณ์แล้วเท่านั้น หากเกิดการยกเลิกคำสั่งซื้อ การปฏิเสธการชำระเงิน (Chargeback) หรือการขอคืนเงินในทุกกรณี บริษัทฯ ขอสงวนสิทธิ์ในการหักกลบลบหนี้หรือระงับการจ่ายค่าคอมมิชชั่นในยอดดังกล่าวทันที

3. การปฏิบัติตามกฎหมายภาษีอากรและประมวลรัษฎากรไทย: รายได้จากค่าคอมมิชชั่นทั้งหมดถือเป็นเงินได้พึงประเมินตามประมวลรัษฎากรแห่งประเทศไทย บริษัทฯ มีหน้าที่ตามกฎหมายในการหักภาษี ณ ที่จ่าย 3% จากยอดจ่ายค่าคอมมิชชั่นก่อนโอนเข้าบัญชีของพาร์ทเนอร์ และพาร์ทเนอร์มีหน้าที่ต้องนำรายได้ดังกล่าวไปยื่นภาษีเงินได้ประจำปีด้วยตนเอง

4. มาตรการป้องกันการทุจริตและจริยธรรมทางการค้า: ห้ามพาร์ทเนอร์กระทำการใดๆ ที่เข้าข่ายหลอกลวง โฆษณาเกินจริง แอบอ้างเป็นบริษัทฯ หรือกระการผิดกฎหมายคุ้มครองผู้บริโภค หากตรวจสอบพบการทุจริต บริษัทฯ มีสิทธิ์ยกเลิกสถานะพาร์ทเนอร์และระงับยอดค้างจ่ายทันทีโดยไม่ต้องแจ้งล่วงหน้า

5. การคุ้มครองข้อมูลส่วนบุคคล (PDPA): พาร์ทเนอร์ยินยอมให้บริษัทฯ เก็บรวบรวม ใช้ และเปิดเผยข้อมูลส่วนบุคคล (รวมถึงสำเนาบัตรประชาชนหรือข้อมูลบัญชีธนาคารเพื่อการโอนเงินและออกหนังสือรับรองหักภาษี ณ ที่จ่าย) ภายใต้พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562
